Your chats are safe now. A crash can't lose them, and you can back everything up to a folder you pick.

## Security
- **Your keys in the backup, if you want.** Turn on "Include API keys and the memory key" and they go into the backup locked with a password you make. A restore brings back your keys, memory and schedules, even on a new Mac.

## Features
- **A crash can't lose your chats.** If E.V closes unexpectedly, your chats, layout and running Claude Code, Codex and terminal sessions come back as they were. E.V tells you when it restored things.
- **Backups to a folder you pick.** Every hour, day, week or your own time. Chats, attached files, settings and Claude Code / Codex conversations. Only what changed is copied and checked. No AI, no tokens. Restore any backup in one click (Settings → Backups).
- **Bring back a deleted chat.** Turn on "Keep deleted chats in the backup" and a deleted chat can come back later from Settings → Backups.
- **What's new.** After each update, a window shows what changed, with a button to each thing. Open it again from Settings → Updates.

## Fixes
- A reply cut off by a crash shows a Continue button that picks up where it stopped.
- Half-typed messages are kept for each chat, even after a restart.
- Sessions still running after a restart go back in the sidebar instead of being closed.
- Asking E.V to look at its own window no longer makes it close; it takes a screenshot instead.
- If the chat list can't be read, E.V stops saving over it and loads the newest good copy.
