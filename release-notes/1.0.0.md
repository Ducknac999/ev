The first public release of E.V — a free, open-source AI assistant for your Mac.

## Features
- Start window: set up Claude Code and/or Codex, API keys, a local model, your passphrase, permissions and voice — every step skippable.
- Any AI you like: DeepSeek, OpenAI, Anthropic, Gemini, OpenRouter, xAI Grok, Mistral, Groq, a custom server, or a free local model through Ollama.
- Claude Code and Codex sessions side by side.
- Controls your Mac in the background: reads windows (including what's off screen), clicks, types and scrolls without moving your mouse.
- Talk to it: "Hey E.V", hold to talk, and a quick panel from any app (⌥Space).
- Learns routes that worked and repeats them with no AI call.
- In-app updates: Settings → General → Check for updates.

## Security
- Sends, deletes and purchases always ask first, behind your own passphrase.
- Updates are signed; E.V only installs ones signed with the project's key.

## UI
- New look: graphite with a mint accent, calmer glows, clearer contrast.
