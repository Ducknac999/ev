Calmer, cleaner panels in every layout, and safer updates.

## UI
- One session list: the Dock is gone; the sidebar (⌘B) works in every layout and marks what's on screen.
- Panels have one clean header (title, status, ⋯) — rename, folder, usage, minimize, close and delete are in the ⋯ menu.
- Steps fold into one line ("✓ 12 steps"); click to see them.
- Claude, Codex and Terminal panels match the theme, with a small usage ring.
- Top bar: Always show, Auto-hide or Compact (Settings → General), and minimized sessions fold into one Tasks menu.
- "Tray" is now "List".

## Features
- Move another E.V on this Mac into this app (Settings → General): keys, chats, memory and running sessions come along.

## Fixes
- Updating while a chat is answering asks first: update when it finishes, or now.
- Building E.V from GitHub no longer fails on a missing resources folder.
